# DEARLY v3

## 새 기능 — AI CHAT MODE
- 현재 생성된 모든 문답을 대상으로 OOC 한 번에 생성
- 질문 내용에 따라 첫만남/과거, 비교, 감정, 갈등·관계 심화, IF, 일상, 표현형 규칙을 자동 선택
- OOC 전체 1,500자 하드 제한 및 실시간 글자 수 표시
- 1,500자를 맞추기 위해 질문을 임의 삭제하지 않음
- 질문 자체가 너무 길어 모든 질문을 1,500자에 담을 수 없을 때 명확한 안내
- {{char}} / {{user}} 표기 직접 변경
- 자연스럽게 / 간결하게 / 근거 중심 답변 스타일
- OOC 원클릭 복사
- AI의 Q1/A1 전체 답변 붙여넣기 → 각 답변칸 자동 분리/적용

기존 v2의 이미지 크롭, 디자인 설정, 자동 높이, PNG 저장 기능도 유지됩니다.
