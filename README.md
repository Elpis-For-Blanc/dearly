# DEARLY

소중한 둘의 이야기를 기록하는 문답 메이커.

## 사용 방법
1. `index.html`, `style.css`, `script.js`를 같은 폴더에 둡니다.
2. `index.html`을 브라우저에서 열면 바로 사용할 수 있습니다.
3. GitHub Pages에 배포하려면 세 파일을 저장소 루트에 업로드하면 됩니다.

## 현재 기능
- 이름 / 페어명
- 이미지 2장 업로드
- 연애 / 일상 / 첫만남 / 관계 심화 / IF / 둘 중 누구? / 랜덤 문답
- 5 / 10 / 15 / 20문답
- 직접 질문 추가 및 삭제
- 답변 실시간 미리보기
- 5가지 컬러 프리셋 + 개별 색상 변경
- 폰트 / 패턴 / 장식 / 결과 비율 변경
- 랜덤 꾸미기
- 모바일 반응형

이미지는 브라우저 안에서만 읽으며 별도 서버로 업로드하지 않습니다.
